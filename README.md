# 工银e生 · 21天扑满计划

像素复古风「养成型」理财互动网页 Demo —— 工行杯参赛作品。以「21天扑满计划」为主线，借鉴旅行青蛙的窗口化养成体验，通过游戏化养成、任务打卡的方式向年轻用户普及理财知识，陪伴用户养成攒钱习惯。

## 在线体验
👉 GitHub Pages 地址： https://livreee.github.io/21day-wealth-script/

如首次打开提示 404，说明 Pages 刚部署，等待约 1 分钟刷新即可。

## 核心玩法
- **5条人生剧情线**：我的小家 / 宝贝计划 / 说走就走 / 自由Gap / 第一次独居，每条线完整 21 天逐日剧情
- **21天扑满养成**：每天完成剧情任务=喂扑满一颗金珠，扑满三幕成长（空罐小奶猪 → 肚里金珠发光 → 金冠满罐）
- **四季温馨小屋**：主界面是温馨小屋，随 21 天进度自动变换春 / 夏 / 秋 / 冬四季场景
- **吉祥物「扑满」**：蜜蜂装扮的像素小猪，6 种表情（默认/开心/惊讶/期待/满足/安睡），点击对话互动，头顶感叹号提示
- **旅行系统（仿旅行青蛙）**：每完成 3 天任务，扑满自动出门旅行，归来带回一件纪念品（12 件各地风物+理财感悟）
- **纪念品图鉴 & 拼豆成就**：收集纪念品解锁旅行主题拼豆徽章（旅行家/探索者/收藏家/环球玩家）+ 8 枚经典拼豆徽章
- **随机存钱挑战**：每日一个谐音梗存钱挑战（金额可自定义），输入金额确认存钱
- **每日理财一问**：零黑话理财答题，答对得金珠
- **好友组队闯关**：小队成员进度展示 + 全队累计 84 金珠团体目标
- **行囊 & 存钱记录**：金珠统计、随手存一笔、每一笔存钱都有记录
- **8-bit 背景音乐**：Web Audio 实时生成轻快复古 BGM + 操作音效

## 项目结构
| 文件 | 说明 |
|---|---|
| `index.html` | 网页版 Demo 主文件（内联样式与脚本） |
| `assets/` | 像素素材：6 张小猪表情（webp）、4 张四季小屋（webp） |

## 本地运行
无需构建、无需依赖，直接用浏览器打开 `index.html` 即可；或在本目录启动一个静态服务器：
```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术特点
- 零框架原生 JS，单 HTML + 素材目录交付，移动端自适应
- 像素点阵视觉 + 工银红品牌色 + 复古 8-bit 风格
- 旅行青蛙式多窗口架构：小屋 / 行囊 / 纪念 / 任务 / 小队
- localStorage 进度存档，刷新不丢进度
- Web Audio API 实时生成 8-bit 背景音乐与音效，无需外部音频文件
