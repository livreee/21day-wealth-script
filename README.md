# 工银e生 · 21天扑满计划

像素复古风养成类理财互动网页 Demo —— 工行杯参赛作品。以「21天扑满计划」为主线，通过游戏化养成、任务打卡的方式向年轻用户普及理财知识，陪伴用户养成攒钱习惯。

## 在线体验
👉 GitHub Pages 地址： https://livreee.github.io/21day-wealth-script/

如首次打开提示 404，说明 Pages 刚开启、正在部署，等待约 1 分钟刷新即可。

## 核心玩法
- **5条人生剧情线**：我的小家 / 宝贝计划 / 说走就走 / 自由Gap / 第一次独居
- **吉祥物「扑满」养成**：右下角全局悬浮小猪存钱罐，随21天进度三幕成长（空罐小奶猪 → 肚里金珠发光 → 金冠满罐）
- **每日任务打卡**：每天一个理财小知识+一个小任务，喂扑满一颗金珠
- **拼豆徽章收集**：8枚像素拼豆徽章，随进度逐步解锁
- **21天旅程日历**：可视化查看每日完成状态
- **攒钱小队**：和朋友一起坚持，互相监督
- **8-bit 背景音乐**：Web Audio 实时生成轻快复古BGM + 操作音效

## 本地运行
无需构建、无需依赖，直接用浏览器打开 `index.html` 即可；或在本目录启动一个静态服务器：
```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术特点
- 单 HTML 文件交付，零运行时依赖，移动端自适应
- 像素点阵视觉 + 工银红品牌色 + 复古 8-bit 风格
- 吉祥物三幕成长形态、对话气泡、投币动画
- 任务打卡、进度状态、徽章收集等交互全部在前端完成
- Web Audio API 实时生成 8-bit 背景音乐与音效，无需外部音频文件
